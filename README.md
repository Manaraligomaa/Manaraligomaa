## ⭐ Featured project

### [Let's Shop — Playwright automation](https://github.com/Manaraligomaa/lets-shop-automation)

End-to-end QA for an e-commerce web app, from the SRS to automated tests in CI.

- **QA process:** SRS static review → user stories with Gherkin acceptance criteria → test cases (EP, BVA, severity, priority) in Jira → manual execution → automation
- **Framework:** Playwright + TypeScript, Page Object Model, custom fixtures, data-driven tests with no hardcoded test data
- **Two layers:** UI tests and fast API tests, with every API response checked against a schema contract
- **Traceability:** every test is tagged with its Jira key, and a custom reporter writes a traceability table
- **Known bugs as tests:** 7 open application bugs are tracked as tests that flag the moment a bug is fixed
- **CI:** lint, typecheck and the full suite on every pull request with GitHub Actions
